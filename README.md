# 동네의 목소리 — 성북구 재개발 구술 지도

**Python 표준 라이브러리 웹서버 + Kakao Maps JavaScript SDK + 공개 행정동 경계 GeoJSON** 기반의 인터랙티브 사이트입니다.

첨부된 「사조방 구술 자료 2.pdf」의 원문 **13개 기록**을 추출·검토하고, 지역별 긍정·부정 발언을 정리했습니다. 전체 발언과 출처 쪽수를 함께 표시하며, 지도의 9개 실제 행정동 경계를 클릭하면 정릉동·길음동·장위동 구술이 열립니다.

## 1. 실행 절차

1. 압축 해제 후 `seongbuk_oral_map` 폴더로 이동합니다.
2. `.env.example`을 `.env`로 복사합니다.
3. [카카오 디벨로퍼스](https://developers.kakao.com/)에 로그인해 애플리케이션을 생성합니다.
4. **카카오맵 → 사용 설정 ON**으로 활성화합니다. (2026년부터 적용되는 이용 조건에 따라 유료 설정이 필요할 수도 있습니다.)
5. **JavaScript 키**의 **JavaScript SDK 도메인**에 아래 주소를 등록합니다.
   - `http://localhost:8000`
   - 필요하면 `http://127.0.0.1:8000`도 등록합니다.
6. `.env` 파일의 `KAKAO_JAVASCRIPT_KEY`에 JavaScript 키를 붙여 넣습니다. **REST API 키가 아닙니다.**
7. 터미널에서 다음을 실행합니다.

```bash
python app.py
```

8. 웹브라우저에서 **http://localhost:8000**을 엽니다.

키가 없어도 발언 분류, 지역 버튼, 검색, 원문 확인 등은 작동합니다. **실제 카카오 지도와 행정동 폴리곤을 표시하려면 개인 키 및 네트워크가 필요**합니다. 최초 접속 시 행정경계 원본 약 33MB를 다운로드한 뒤 9개 행정동만 선별하여 `data/seongbuk_boundaries_20261001.geojson`에 저장하므로 이후에는 경계 다운로드가 필요하지 않습니다. 맵 타일 표시는 인터넷 연결을 필요로 합니다.

### 시스템 구성

| 파일 | 기능 |
|---|---|
| `app.py` | Python 표준 라이브러리 HTTP 서버 및 JSON API, 경계 다운로드·추출 |
| `static/index.html` | 사이트 구조 |
| `static/style.css` | 화면 디자인, 모바일 반응형 |
| `static/main.js` | 지도 다각형 클릭, 필터, 검색, 원문 표시 |
| `data/source.pdf` | 제공받은 원본 구술 자료 |
| `data/annotations.json` | 구술 13개에 대한 연구자의 수작업 코딩 |
| `data/records.json` | 원문 전체+찬반 태그가 포함된 완성 데이터 |
| `data/classified_quotes.csv` | 인용문 단위 분류 결과 16행, 엑셀에서 사용 가능 |
| `build_data.py` | PDF → 원문 추출 → 코딩 조합 → JSON/CSV 생성 |
| `tests/test_project.py` | 구술 수, 원문 정확성, 유형별 통계, 지오JSON 필터 단위 테스트 |

## 2. 구술 분석 기준

| 지역 | 구술 기록 | 긍정 코드 | 부정 코드 |
|---|---:|---:|---:|
| 정릉동 | 1 | 0 | 1 |
| 길음동 | 3 | 0 | 3 |
| 장위동 | 9 | 4 | 8 |
| **계** | **13** | **4** | **12** |

- **긍정:** 노후 건물·주거 환경 개선, 개발 필요성, 사업 추진 선호 및 가치 상승 기대
- **부정:** 입주·이주 비용, 원주민 이탈, 상가 보상·생업 단절, 강제철거, 공동체 해체
- **양면적 사례:** 장위동 우덕수(5), 노정열(6), 식료품점 운영자 김씨(13). 각 발언을 긍정·부정 **둘 다** 표시합니다. 따라서 13개 기록에서 총 16개의 찬반 코드가 집계됩니다.
- 길음동 오복례(4)는 노후 집 문제를 언급하지만 찬성을 명시하지 않았고 생업 재정착을 강하게 우려하므로 부정으로 분류했습니다. 해석이 필요하면 `annotations.json`에서 수정 후 다시 생성할 수 있습니다.
- 구술상의 재산가치, 보상금, 이주 인원·매출 비율 등은 **화자의 진술**입니다. 별도로 검증한 통계로 취급하지 않습니다.
- 정릉 기록은 ‘재건축’, 다른 일부 기록은 ‘재개발’이라는 용어를 사용하므로, 사이트에서는 이를 **도시정비사업에 대한 반응**으로 함께 탐색하지만 원문의 표현은 그대로 유지합니다.
- 이 분류는 발언 내용의 수작업 질적 코딩이며 13개 기록으로 전체 주민의 찬반 비율을 추정할 수 없습니다.
- 구술 자료에는 인터뷰 대상자의 이름과 구체적 경험이 포함됩니다. **사이트를 인터넷에 공개하기 전** 구술 자료의 저작권·사용 허락 범위 및 공개 동의 여부를 확인하시기 바랍니다.

## 3. 행정동 경계와 구술 지역의 차이

구술 PDF의 ‘정릉동·길음동·장위동’은 **연구 자료의 묶음**입니다. 성북구의 실제 행정동은 다음 9개로 나뉩니다.

- 정릉동 지역 → **정릉1동·정릉2동·정릉3동·정릉4동**
- 길음동 지역 → **길음1동·길음2동**
- 장위동 지역 → **장위1동·장위2동·장위3동**

따라서 지도에서는 9개 행정동 폴리곤을 그린 뒤 **어느 세부 행정동을 클릭하더라도 해당 구술 자료의 대분류가 표시**되도록 하였습니다. PDF에 없는 구술 장소의 정확한 세부 위치는 추정하지 않습니다.

**경계 데이터 출처:** 통계청 SGIS 공공누리 제1유형 원자료를 가공한 [vuski/admdongkor](https://github.com/vuski/admdongkor) 2026-10-01판, **CC BY 4.0**. © 통계청 SGIS, 가공: vuski/admdongkor. 원본 자료가 변경되거나 위치가 정확하지 않을 수 있습니다. 공식 측량·법적 경계 확인 목적으로 사용하지 마십시오.

## 4. PDF 데이터 다시 생성하기 (선택)

구술 원문/주석을 갱신하는 경우:

```bash
pip install pymupdf
python build_data.py
python -m unittest discover -s tests -v
```

`build_data.py`는 원본 PDF의 내용을 화자별로 추출하고, **사람이 검토한** `annotations.json`의 긍정·부정 근거 인용문이 원문에 실제 존재하는지 확인합니다. 근거에 없는 자동 감성분석 결과를 생성하지 않습니다.

## 5. API와 외부 의존성

- `GET /api/records` (`?region=장위동&stance=긍정` 지원)
- `GET /api/summary`
- `GET /api/boundaries` (처음 한 번 GitHub에서 2026 행정동 원본 취득)
- `GET /api/config`
- `GET /source.pdf`
- `GET /health`

일반 사이트 실행에 별도 Python 패키지는 필요하지 않습니다. PDF 재추출에만 PyMuPDF가 필요합니다.

### 카카오맵이 표시되지 않으면

1. 발급한 키가 **JavaScript 키**인지 확인합니다.
2. JavaScript SDK 도메인에 입력한 주소와 실제 접속 주소가 **프로토콜/호스트/포트까지 동일한지** 확인합니다.
3. 카카오맵 사용 설정 ON 및 쿼터/과금 활성화 상태를 확인합니다.
4. `http://localhost:8000/api/boundaries`를 열어 `features`가 **9개**인지 확인합니다. 네트워크 차단 시 공개 GeoJSON을 다운로드하지 못할 수 있습니다.
5. 브라우저 개발자 도구(F12)의 콘솔/네트워크 탭에서 SDK 오류를 확인합니다.
